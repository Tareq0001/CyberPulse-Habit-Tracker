## 🌟 مميزات المشروع
- **حفظ محلي 100%:** جميع بيانات العادات تحفظ في متصفحك عبر `localStorage` بخصوصية كاملة.
- **حساب سلاسل الالتزام (Streaks 🔥):** تتبع عدد الأيام المتتالية لإنجاز كل عادة تلقائياً.
- **خريطة النشاط والالتزام (Activity Matrix):** مصفوفة مربعات تحاكي أسلوب GitHub لعرض كثافة نشاطك خلال آخر 28 يوماً.
- **تصدير واستيراد البيانات:** إمكانية حفظ نسخة احتياطية بصيغة JSON واسترجاعها في أي وقت.
- **دعم ثنائي للغة:** تبديل فوري بين العربية (RTL) والإنجليزية (LTR).
